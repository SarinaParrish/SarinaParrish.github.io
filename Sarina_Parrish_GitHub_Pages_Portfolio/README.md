# Sarina Parrish — Portfolio

Static portfolio site designed for GitHub Pages.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named exactly `SarinaParrish.github.io`.
2. Upload everything in this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will publish the site at `https://sarinaparrish.github.io`.

## Files

- `index.html` — page content
- `styles.css` — responsive site styling
- `script.js` — small footer-year script
- `assets/Sarina_Parrish_Resume.docx` — downloadable resume

The site links to the existing public project repositories and the live Streamlit app.
